## 🧭 4つの実践章（エンドツーエンドの完全なクローズドロジック）

* [**第1章：グローバル主要アフィリエイトプラットフォームの比較と落とし穴 (PartnerStack vs Rewardful vs Impact)**](./docs/01-platforms.md)
  * なぜSaaSにはPartnerStackが最適なのか、個人向けツールの基盤がなぜRewardfulばかりなのか、そして公式サイトのフッターにある「検索キーワードの裏技」を徹底解説。
* [**第2章：越境送金チャネルの比較と W-8BEN 免税コンプライアンスガイド (Wise vs PayPal)**](./docs/02-payout-taxes.md)
  * 「プラットフォーム `$	o$` Wise ACH `$	o$` 国内Alipayへ秒速着金」という手数料ゼロのパイプラインをマスターし、W-8BENの記入によって30%の源泉徴収税を0%にする方法をハンズオンで解説。
* **第3章：プログラマーの放置資産の活用ガイド（マネタイズ実践）**
  * **オープンソースプロジェクトの README**：`Powered by` バッジをエレガントに埋め込む方法；
  * **個人ブログの `/uses` ページ**：コンバージョン率 5%〜10% を誇るギーク向けのハードウェア・ソフトウェアリスト；
  * **フルスタックコードのボイラープレート (Boilerplate)**：メール、データベース、認証サービスをあらかじめ組み込み、下流の収益分配を直接獲得する手法。

## 🔍 TOP 10 パートナーのディープな分解とギーク向け選定ガイド

### 🥇 Notion (生産性向上・チームコラボ)

- **報酬構造**：`50% 初回/年間サブスクリプション報酬`
- **基盤ネットワーク**：PartnerStack
- **参入ハードル**：低 (個人プロフィールを記入するだけ)
- **対応決済方法**：Stripe / PayPal / Direct ACH (Wise)
- **コア解説**：世界最高峰のナレッジベースおよびノートテイキングアプリ。開発者コミュニティでの浸透率が非常に高いため、チーム版へのアップグレードによるコンバージョン率が非常に高く、多通貨決済に対応しています。
- 🔗 **公式パートナー登録**：[Notion 公式アフィリエイトプログラムへ](https://affiliate.notion.so)

---

### 🥈 DigitalOcean (クラウドホスティング・基礎計算)

- **報酬構造**：`$25 キャッシュバック (ユーザーは $200 クレジット)`
- **基盤ネットワーク**：公式サイト直営 (In-House)
- **参入ハードル**：非常に低 (登録するだけで招待コードを取得可能)
- **対応決済方法**：PayPal / サーバー利用料相殺
- **コア解説**：定番の個人開発者向けクラウドサーバー。オープンソースプロジェクトのREADMEや、技術ブログの「ワンクリックサーバーデプロイ」チュートリアルに組み込むのに最適です。
- 🔗 **公式パートナー登録**：[DigitalOcean 公式アフィリエイトプログラムへ](https://www.digitalocean.com)

### 🥉 Make.com (自動化・ワークフロー連携)

- **報酬構造**：`20% 永久継続報酬 (Lifetime)`
- **基盤ネットワーク**：PartnerStack
- **参入ハードル**：中 (プロモーションチャネルの説明が必要)
- **対応決済方法**：Stripe / PayPal / Wise
- **コア解説**：Zapierの強力な代替ツールであり、複雑なAPIやWebhookの連携をサポート。顧客が毎月ワークフローのクォータを購入する限り、継続的に月次キャッシュバック報酬を受け取ることができます。
- 🔗 **公式パートナー登録**：[Make.com 公式アフィリエイトプログラムへ](https://www.make.com/en/affiliates)

### 4️⃣ Beehiiv (グローバル向けニュースレター・メールマーケティング)

- **報酬構造**：`50% 継続報酬 (最大 12 ヶ月)`
- **基盤ネットワーク**：PartnerStack
- **参入ハードル**：低 (即時利用可能)
- **対応決済方法**：Stripe / PayPal
- **コア解説**：海外で最もホットなクリエイター向けメールプラットフォーム。1顧客あたりの月額料金は $40〜$100 程度で、1人のクリエイターのサブスクリプションを紹介するだけで、年間数百ドルの収益を生み出せます。
- 🔗 **公式パートナー登録**：[Beehiiv 公式アフィリエイトプログラムへ](https://www.beehiiv.com)

### 5️⃣ Typefully (SNS・X(Twitter)の文章作成・プレビュー)

- **報酬構造**：`20% 永久継続報酬 (Lifetime)`
- **基盤ネットワーク**：Rewardful (Stripe基盤)
- **参入ハードル**：非常に低 (公式サイトから即座に開設可能)
- **対応決済方法**：Wise / PayPal
- **コア解説**：グローバルに展開する個人開発者に選ばれているX/Threads向けのライティングツール。Rewardfulを基盤としているため審査が瞬時に通過し、優れたマイクロSaaSの典型的な成功事例です。
- 🔗 **公式パートナー登録**：[Typefully 公式アフィリエイトプログラムへ](https://typefully.com)

- **コア解説**：客単価が非常に高いデザイン・フロントエンド構築ツール。企業向け顧客のサブスクリプション単価が高いため、1件の紹介で数百から数千ドルのリターンを得られます。

### 8️⃣ Wise (国際送金・マルチカレンシー口座)

- **報酬構造**：`約 $65 キャッシュボーナス (アクティブユーザー 3 名紹介ごと)`

- **参入ハードル**：非常に低 (アカウントを保有していれば紹介可能)

- **コア解説**：グローバル活動における資金のライフライン。米ドルの受取や海外送金を希望する開発者にとって紹介のハードルが極めて低く、報酬が直接アカウントに入金されます。
